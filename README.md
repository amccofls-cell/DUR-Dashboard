# DUR Dashboard v1.0

Windows에서 Python 설치 없이 사용할 수 있는 로컬 DUR 품목 조회 대시보드입니다. GitHub Actions가 Windows EXE를 자동 빌드합니다.

## v1.0 주요 기능

- 8개 DUR Excel 파일을 **한 번에 선택**하면 파일명과 시트/헤더 구조를 이용해 자동 분류
- 각 파일의 **모든 시트**를 로컬 SQLite 검색 인덱스로 생성
- 품목명을 **여러 개 한 번에 입력** (한 줄에 하나, 쉼표/세미콜론도 지원)
- 품목명의 일부를 입력하면 등록된 품목명 후보 중 가장 가까운 후보를 조회
- 결과를 **약품별 결과**와 **DUR 종류별 결과** 두 화면으로 제공
- 병용금기 급여/비급여, 연령금기, 임부금기, 수유부주의, 효능군중복, 비대면진료 처방금지, 비용효과적 함량 통합 조회
- 임부금기 등급, 연령 조건 및 원본 시트/상세 필드 표시
- 기준파일 누락/오류 시 `해당 없음` 대신 `확인불가` 표시
- 데이터는 PC 내부에서만 처리

## EXE 만들기

1. 이 저장소의 파일을 GitHub에 업로드합니다.
2. GitHub의 **Actions** 탭을 엽니다.
3. **Build Windows EXE** workflow를 선택합니다.
4. **Run workflow**를 누릅니다.
5. 빌드가 끝나면 실행 페이지 하단 **Artifacts**에서 `DUR-Dashboard-Windows`를 다운로드합니다.
6. 압축 안의 `DUR_Dashboard.exe`를 실행합니다.

사용자 PC에 Python을 설치할 필요가 없습니다.

## 기준파일 등록

프로그램에서 `DUR 파일 한 번에 등록` 버튼을 누르고 최대 8개 Excel을 동시에 선택합니다. 파일명에 `병용금기 급여`, `병용금기 비급여`, `연령금기`, `임부금기`, `수유부주의`, `효능군중복`, `비대면진료`, `비용효과`가 포함되어 있으면 자동 분류합니다. 이름이 불명확한 경우 시트명과 헤더 구조를 추가로 확인합니다.

원본 Excel은 GitHub에 업로드할 필요가 없습니다.

## v1.1 변경사항
- 병용금기 급여/비급여 대용량 파일은 모든 시트를 검색하되 **A, D, F, G, J, M, N, O 열만 인덱스에 저장**합니다.
  - A 성분명A / D 제품명A / F 급여여부A / G 성분명B / J 제품명B / M 고시번호 / N 고시일자 / O 상세정보
- 병용금기는 D열 제품명A와 J열 제품명B를 모두 검색 엔트리로 만들어 양방향 조회합니다.
- 전체 DUR 상세 조회 화면에서 **성분코드, 주성분코드, 일반명코드, 제품코드, 약품코드, 업체명**은 표시하지 않습니다.
- 위 필드는 화면에서만 숨기며, 병용금기를 제외한 원본 인덱싱 구조는 검색 정확도를 위해 유지될 수 있습니다.
