# DUR Dashboard v1.4

Windows용 로컬 DUR 통합 조회 대시보드입니다. 인터넷/Notion 없이 등록한 Excel 기준파일만 사용합니다.

## v1.4 변경사항

- **품목 일괄 검색 후보 선택**: 여러 검색어를 입력하면 각 검색어별 후보 품목이 드롭다운으로 표시됩니다. 사용자가 함량/제형을 확인해 실제 조회할 품목을 직접 선택한 뒤 통합 조회합니다.
- **연령금기/비대면진료 누락 보정**: DUR 파일별 품목명 표기 차이(성분 괄호, 수출명, 포장단위 등) 때문에 동일 품목이 정확 문자열 일치에서 빠지던 문제를 보정했습니다.
- 비대면진료 파일에서 한 셀에 여러 품목명이 쉼표/세미콜론으로 들어 있는 경우 각 별칭도 검색 인덱스에 등록합니다.
- 연령금기의 `특정연령단위` / `특정연령단위코드` 표시를 인식합니다.
- 기존 v1.3 DB도 조회 가능하도록 연령금기/비대면진료에 호환 fallback을 넣었습니다.
- 정확한 신규 인덱스를 만들기 위해 v1.4 최초 실행 후 **기준파일 관리 → 다시 인덱싱**을 한 번 실행하는 것을 권장합니다.

## 기존 기능

- 8개 DUR Excel 일괄 등록 및 자동 분류
- 모든 시트 검색
- 병용금기 급여/비급여 동시 검색
- 병용금기 대용량 파일은 A/D/F/G/J/M/N/O 열만 인덱싱
- 여러 품목 동시 검색
- 약품별 결과 / DUR 종류별 결과
- 기준파일별 마지막 등록 일시 저장
- 성분코드/제품코드/업체명/원본 출처는 결과 화면에서 숨김

## GitHub Actions로 Windows EXE 만들기

1. 이 ZIP의 내용물을 GitHub 저장소 최상위에 업로드합니다.
2. GitHub의 **Actions** 탭에서 `Build Windows EXE`를 선택합니다.
3. **Run workflow**를 실행합니다.
4. 완료 후 Artifacts에서 Windows 빌드 ZIP을 받습니다.
5. 압축 안의 `DUR_Dashboard.exe`를 실행합니다.

사용자 PC에 Python을 설치할 필요가 없습니다.
