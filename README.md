# DUR Dashboard v1.4.1

Windows용 로컬 DUR 품목 조회 대시보드입니다. GitHub Actions에서 EXE를 빌드할 수 있으며 사용자 PC에는 Python 설치가 필요하지 않습니다.

## v1.4.1 수정사항
- `오코돈서방정40밀리그램` 사례를 기준으로 연령금기/비대면진료 처방금지 누락 문제를 재검증했습니다.
- 동일 품목을 DUR 파일별 문자열만으로 연결하지 않고, 화면에는 표시하지 않는 **내부 제품코드**도 보조 식별자로 사용합니다.
- 조회 우선순위: 정규화 품목명 완전일치 → 핵심 품목명 일치 → 내부 제품코드 일치 → 연령금기/비대면진료 안전한 부분일치.
- 제품코드는 조회 결과 UI에는 표시하지 않습니다.
- 병용금기 파일은 기존과 동일하게 A/D/F/G/J/M/N/O 열만 인덱싱하며 제품코드는 추가로 읽지 않습니다.
- 품목 일괄 검색 시 일부 검색어 입력 → 후보 드롭다운 → 정확한 품목 선택 방식은 유지합니다.

## 확인된 테스트 사례
`오코돈서방정40밀리그램(옥시코돈염산염)_(40mg/1정)`을 2026-09 기준 파일에서 테스트한 결과:
- 연령금기: `18세 미만`, 상세 `안전성 및 유효성 미확립`
- 비대면진료 처방금지: 해당, 분류 `마약류의약품`

## 업데이트 후 권장 작업
새 EXE를 처음 실행한 뒤 **기준파일 관리 → 다시 인덱싱**을 한 번 실행해 주세요. 기존 등록 파일은 그대로 사용할 수 있습니다.

## GitHub Actions 빌드
1. 이 패키지의 내용을 저장소 최상위에 업로드합니다.
2. GitHub `Actions` → `Build Windows EXE` → `Run workflow`를 실행합니다.
3. 완료 후 Artifact에서 Windows EXE를 내려받습니다.
