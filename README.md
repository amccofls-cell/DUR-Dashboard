# DUR Dashboard

Windows에서 Python 설치 없이 사용하는 로컬 DUR 품목 조회 대시보드입니다.

## EXE 만들기

이 저장소의 **Actions** 탭에서 **Build Windows EXE**를 선택한 뒤 **Run workflow**를 누릅니다. 빌드가 완료되면 실행 결과 페이지 하단의 **Artifacts → DUR-Dashboard-Windows**를 내려받아 압축을 풉니다.

`DUR_Dashboard.exe`를 실행하면 됩니다. Windows PC에 Python을 설치할 필요가 없습니다.

## 사용 방법

1. 왼쪽 기준파일 관리 영역에서 8개 DUR Excel 원본을 각각 등록합니다.
2. 프로그램이 각 Excel의 모든 시트를 읽어 로컬 검색 인덱스를 만듭니다.
3. 품목명 일부를 검색하고 정확한 품목/함량 후보를 선택합니다.
4. 병용금기, 연령금기, 임부금기, 수유부주의, 효능군중복, 비대면진료 처방금지, 비용효과적인 함량 결과를 카드와 상세정보로 확인합니다.
5. 다음 달 품목리스트가 갱신되면 해당 DUR 파일만 다시 등록하면 됩니다.

## 데이터 처리

- DUR Excel 데이터는 GitHub에 업로드할 필요가 없습니다.
- 프로그램에서 선택한 Excel은 사용자 PC 내부에서만 처리됩니다.
- 인터넷이나 Notion을 DUR 판정 데이터로 사용하지 않습니다.
- 파일/시트 읽기에 실패한 경우 해당 상태를 확인불가로 표시하도록 설계되어 있습니다.

## 기준 파일 슬롯

- 병용금기 급여
- 병용금기 비급여
- 연령금기
- 임부금기
- 수유부주의
- 효능군중복
- 비대면진료 처방금지
- 비용효과적인 함량

> 이 프로그램의 결과는 등록된 Excel 원본 데이터에 의존합니다. 최신 기준 파일을 등록했는지 확인하세요.
