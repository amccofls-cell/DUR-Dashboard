# DUR 품목리스트 조회 프로그램 v1.7

Windows용 로컬 DUR 품목리스트 조회 프로그램입니다.

## v1.7 주요 변경사항
- 좌측 사이드바(DUR 조회 / 기준파일 관리) 기반으로 화면을 전면 개편
- 결과 화면에 **약품별 보기 / DUR별 보기** 전환 추가 (DUR 항목별로 해당 품목을 묶어서 확인)
- **품목 묶음 저장·불러오기** 추가: 선택한 품목을 이름을 붙여 저장하고, 저장된 묶음을 클릭하면 품목 검색 없이 바로 조회
  - 묶음은 `%LOCALAPPDATA%\DUR_Dashboard\product_sets.json`에 품목명만 저장되며, 조회는 항상 최신 기준파일로 수행
- 검색어만 입력하고 Enter를 눌러도 품목이 추가되지 않도록 변경 (후보 목록에서만 선택)
- 선택한 품목이 많을 때 선택 목록에 스크롤을 적용하고 **선택 품목으로 조회** 버튼을 하단에 고정
- 오류 수정: 긴 품목명 행의 삭제(✕) 버튼 가림, DUR 카드 hover 오동작, 사이드바 활성 표시, 기준파일 관리 후 결과 화면 유지, 후보 목록 닫힌 뒤 빈 공간 등

## v1.6.1 주요 변경사항
- 품목명 표기 변이(그람/그램) 통일로 구표기 후보를 선택해도 모든 DUR이 조회됨 (기존 DB는 첫 실행 시 자동 보정)
- 후보 전용 테이블과 입력 디바운스로 품목 검색 속도 개선
- 상세정보 글씨 확대, 드래그 선택·복사 기능 추가
- 병용금기 상세 표에 열 정렬, 행 복사, 스크롤바, 표/상세내용 크기 조절 추가
- 상세정보에서 일반명코드 등이 노출되던 문제 수정

## v1.6 주요 변경사항
- 승인된 미리보기 디자인을 기준으로 UI/UX 전면 개선
- Pretendard가 PC에 설치되어 있으면 자동 적용하고, 없으면 맑은 고딕으로 대체
- 전체 글자 크기 확대 및 카드/표/버튼 여백 개선
- 품목 검색을 좌측 검색 패널에 배치하고 자동 후보 목록을 검색창 바로 아래 표시
- 선택한 품목을 누적 카드 형태로 관리하며 개별 삭제/전체 삭제 지원
- DUR 결과를 컬러 카드로 구분하고 상세 탭 가독성 개선
- 우측 하단 `Created by Chaereen Jeong` 유지
- 기준파일 관리 화면에서 **각 기준파일 개별 삭제** 기능 추가
- **전체 기준파일 삭제** 기능 추가
- 삭제 시 프로그램 내부 Excel 복사본 + SQLite 인덱스 + 등록정보를 제거
- 외부에서 사용자가 원래 보관 중인 Excel 파일은 삭제하지 않음
- 삭제 후 새 파일을 다시 등록해 즉시 인덱싱 가능
- 연령금기/비대면진료 원본 Excel 직접 확인 fallback 유지
- 병용금기 급여/비급여는 A, D, F, G, J, M, N, O 열만 인덱싱

## 폰트
프로그램은 Pretendard가 Windows에 설치되어 있으면 우선 사용합니다.
폰트 파일 자체는 패키지에 포함하지 않습니다.

## GitHub Actions 빌드
1. ZIP의 내용물을 저장소 최상위에 업로드합니다.
2. GitHub `Actions` → `Build Windows EXE` → `Run workflow`
3. 완료 후 `DUR-Dashboard-Windows` artifact를 다운로드합니다.
